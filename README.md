## Getting Started

### Usage

1. Download the latest release.
2. Launch `Launcher.exe`.
3. Start the game manually.
4. Once the game is open, press the `INSERT` key to open the GUI.

## Features

### Character / Combat
- God mode
- Instant kill
- No skill cost — battle energy
- Damage multiplier: ×1–1000
- Heal multiplier: ×1–1000
- Infinite summon duration
- Dumb enemies
- Instant win
  
### Custom Stats
- 92 named stat overrides
- Set individual raw values
- Add, remove or clear overrides
  
### Camera / Story / Misc
- Camera FOV adjustment
- Auto dialogue — choices remain manual
- Auto skip story
- Skip story now
- Hide story HUD
- Skip battle summary
- Draggable FPS counter
